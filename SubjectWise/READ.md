## 🎯 Recommended GATE Preparation Strategy

For every subject, follow:

```text
Learn Concepts
      ↓
Make Notes
      ↓
Practice Questions
      ↓
Solve Topic-Wise PYQs
      ↓
Analyze Mistakes
      ↓
Revise
      ↓
Full-Length Mock Tests
```

### ⭐ Golden Rule

> **Concept → Practice → PYQ → Analysis → Revision → Mock Test**

Do not only collect resources. **Complete them and solve questions.**

## 📌 How to Use This Repository

### For Beginners

1. Start with the syllabus.
2. Learn the concepts from one primary resource.
3. Make short notes.
4. Solve basic questions.
5. Move to GATE PYQs.
6. Mark difficult questions.
7. Revise weak topics.

### For Revision

Use:

* Short notes
* Important formulas
* PYQs
* Marked questions
* Important topics
